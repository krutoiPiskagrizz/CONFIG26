# Практическая работа №1. Эмулятор языка оболочки ОС

Вариант №24. Консольный эмулятор оболочки UNIX-подобной ОС на Python 3
(сторонние библиотеки не нужны).

## Структура проекта

```
src/emulator.py   исходный код эмулятора
tests/            стартовые скрипты (.emu) и тестовые скрипты (.sh)
run.sh, run.bat   запуск эмулятора (macOS/Linux и Windows)
```

## Запуск

```bash
./run.sh
```

Приглашение к вводу содержит имя VFS: `user@<имя VFS>:<каталог>$`.
Строка разбирается с учётом кавычек: `ls "my folder"` передаёт один
аргумент. Неизвестная команда и неверные аргументы дают сообщение об
ошибке, эмулятор продолжает работу.

## Этап 1. Команды

| Команда | Описание                                         |
|---------|--------------------------------------------------|
| `ls`    | заглушка: печатает своё имя и аргументы          |
| `cd`    | заглушка: печатает своё имя и аргументы          |
| `exit`  | выход из эмулятора                               |
